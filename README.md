# Флэш-тест — учись без стресса

Простое приложение для самостоятельного тестирования с карточками.

## Возможности

- Создание колод и карточек
- Редактирование и удаление карточек
- Тестирование с переворотом карточек
- Режим "Знаю без подсказки" — честная оценка знаний
- Статистика после теста
- Работает офлайн (PWA)
- Данные хранятся в браузере (localStorage)

## Установка на телефон

1. Открой сайт в браузере на телефоне
2. Нажми «Поделиться» → «На экран «Домой»»
3. Приложение появится как отдельная иконка

## Технологии

- HTML/CSS/JavaScript (чистый фронтенд)
- Service Worker для офлайн-режима
- localStorage для хранения данных
